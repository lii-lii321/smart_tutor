01 · DESIGN PRINCIPLES

设计原则与方向

三条核心主张构成 UI 2.0 的骨架，所有页面与组件的取舍都回溯到这里。

墨黑 = 动作

主 CTA、激活态、深色块一律使用墨黑 #1c1c1e。白字压墨黑对比度 17:1，行动入口在界面中最重、最不可错过。

明黄 = 记忆点

品牌黄 #ffd02f 只做点缀：Logo、推荐位、badge、强调卡。只出现、不铺开，永远不承载正文，避免抢夺内容。

品牌蓝 = 链接

链接与次级强调统一走品牌蓝 #4262ff（压白底 4.8:1，达 AA）。浅蓝 tint 承载选中态、步骤条与 ghost 按钮。

四条执行纪律

纪律含义
单一视觉来源页面与组件只允许消费 --st- 变量或 Tailwind 语义类，换主题 = 只改 design-tokens.css。
色相收敛全站只保留 4 个状态色相 + 中性灰，程度差异用 soft / mid / DEFAULT / deep 四档表达，不为单个场景新开色相。
字阶封顶一屏字阶 ≤ 4 级（display 除外），字号下限 11px，禁止 text-[Npx] 任意值。
克制装饰无炫技动效、无重渐变、无装饰噪声；动效只保留 0.18s 的按压/悬停反馈。

08 · GUARDRAILS

落地守则

写进 Code Review 清单的八条，新页面合并前逐条核对。

✓ 应该做

  • 颜色一律用语义类：bg-surface / text-secondary / text-success-deep
  • 字号一律用 text-caption ~ text-display 七档
  • 按钮、卡片走 AppButton / AppCard（或 st-card 基类）
  • chip 用 soft|mid 底 + deep 字的四档搭配
  • 金额数字加 tabular-nums， 千分位格式化
  • 每个可交互元素有 hover + active + focus 三态

    • ✕ 禁止做

  • 裸写 hex、rgba 色值（floating 阴影除外）
  • text-[Npx]、text-[11.5px] 等任意字号
  • 为单个场景新开色相（sky/violet/emerald…）
  • warning 实心底配白字（仅 3.6:1），一律用 warning-deep
  • 品牌黄铺大面积背景或做正文文字色
  • 页面自造阴影 / 圆角 / 间距魔法数

    • 治理指标（验收口径）

    指标当前目标
    views/components 下裸 hex0 处 ✓（原 46，已清零 + 护栏拦截）0 处
    text-[Npx] 任意字号0 处 ✓（原 174，已按映射表归一）0 处
    原生 button 手写样式128 处（= 复审 G4，分批迁移待做）≤ 20 处（特殊布局豁免）
    focus-visible 覆盖全部 ✓（全局基线自动生效）全部可交互元素
    < 11px 字号0 处 ✓保持 0 处

    一句话总结：这个项目不需要重新设计 —— 设计上限已经很高（token 体系、对比度实测、响应式细节都在水准之上），需要的是把已经设计好的系统执行到位。P1/P3 已于 2026-10-05 当晚清零收官；剩余提升 = P2 的按钮入口收敛（复审 G4）与 P4 的暗色模式/规范层去留。
