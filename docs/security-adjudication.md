# Mimosa 安全扫描裁决基线

> 用途：安全扫描报警后**先对照此单**再动手——已裁决条目不再重复消耗分析时间，
> 新增发现按同样格式补录。裁决原则：静态扫描不理解运行时边界（ORM 参数化、
> 运维脚本无不可信输入、随机数的非安全用途），人工复核结论落在这里。

## 裁决记录

## 复核方法备忘

- SQL 注入类：看 `db.execute()` 的实参是 SQLAlchemy 表达式对象还是 f-string/`%`/`format` 拼的字符串；后者才是真问题
- 路径穿越类：追参数来源——部署环境变量/运维脚本硬编码 ≠ 用户输入
- 随机数类：确认用途。令牌/密钥/防爆破场景必须 `secrets`；脱敏抖动、演示数据用 `random` 是对的
