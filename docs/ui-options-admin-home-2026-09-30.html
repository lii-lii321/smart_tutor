P0 · 编造的指标

「本月已节约 2.1 小时手工录入」是前端估的

Dashboard.vue:35 写的是 savedMinutes = orders_imported * 3——42 单 × 3 分钟 = 2.1 小时。那个「3 分钟/单」在后端没有出处，是写死在前端的系数。

按这个项目一贯的原则（没有后端来源的指标就不产出，不 mock、不估算），它不该以事实的口吻出现在首页。截图里 2.1 小时那个数字就是这么来的。

→ 删掉，或改成后端记录真实耗时
P1 · 移动端必然溢出

「最近订单」4 列表格在手机上被裁掉

你第二张截图里，信息费列只剩一个「信...」——Dashboard.vue:335 写了 min-w-[520px] 的表格塞进约 340px 的视口，必然横向溢出，中介看不到每单能赚多少。

顺带：class="mono"（订单号字体）utilities.css 里没定义，是个空 class，#成都家教05261 现在用的是默认比例字体。

→ 移动端改行卡，不用表格
