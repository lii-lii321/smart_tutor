## 1. 教员端（手机视口 F12 → 390×844 最佳）

- [ ] **橱窗地图**：`/teacher/board/tx886` 打开，地图图钉带价格标签，计数正确
- [ ] **筛选**：筛选面板选学段/科目 → 地图图钉与列表联动；重置恢复
- [ ] **城市切换**：选"北京市" → 成都单全部隐藏；选回"全部城市"恢复
- [ ] **推荐**：登录后推荐抽屉出现匹配分；未登录显示引导登录
- [ ] **投递**：点图钉 → 订单面板 → 去投递 → 我的投递出现"待审核"
- [ ] **取消投递**：待审核状态可自助取消
- [ ] **地址解锁**：对"试课中"订单（预置 trial 单）能看家长电话；招聘中订单看不到
- [ ] **通知**：角标数正确；一键已读后角标清零
- [ ] **费用**：金额与预置流水一致（定金 6×100、尾款 360、退款 100、没收 100）
- [ ] **简历**：新增/编辑/设默认/删除；首份自动默认
- [ ] **注销**（⚠️ 不可逆，建议最后测或跳过）：注销后原手机号可重新注册

## 2. 中介后台（B 端）

- [ ] **批量解析**：粘贴一段微信订单文本 → AI 解析出结构化预览（需 DEEPSEEK_API_KEY）
- [ ] **导入上架**：确认后地图出现新单；重复导入提示跳过
- [ ] **审核全链**：投递审核页选订单 → 加入候选 → 确认定金 → 开始试课 → 确认尾款 → 确认完成
- [ ] **试课失败**：填家长试课酬，预览退款 = max(0, 已收 − 试课酬×70%)；确认后订单重开
- [ ] **没收**：教员违约路径，流水记没收
- [ ] **成交自动退款**：同一订单两个教员都付定金后成交其一 → 另一教员自动"已退款"且财务有退款流水（本批修复的重点，务必测）
- [ ] **改价不追溯**：成交流程中在订单编辑改 base_price → 该教员尾款仍按定金时快照收（本批修复重点）
- [ ] **归档/重开**：归档后 republish / batch 重开均可；有未处置定金时重开被拦（409 提示）
- [ ] **财务页**：四类流水齐全，CSV 导出可打开
- [ ] **我的教员**：档案+黑名单；拉黑后该教员投递被拒、推荐屏蔽；移出恢复
- [ ] **通知**：新投递/成交待退定金/临期提醒出现
