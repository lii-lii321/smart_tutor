# 智派家教 · 中介工作台使用指引（Pilot 版）

> 给参与试用的中介老师：这份指引覆盖日常最常用的 5 件事。手机浏览器（建议微信内打开）
> 访问你的专属链接即可，无需安装 App。

## 1. 登录

- 手机访问：`https://<你的域名>/admin/login`
- 输入**中介邀请码**（由平台发放）+ **密码**，点「进入中介后台」
- 密码遗忘请联系平台重置

## 2. 每天打开第一眼：工作台

登录后就是**工作台**，从上到下：

- **今日工作摘要**：招聘中 / 试课中 / 待审核投递 / 未读消息（点数字直接去对应页面）
- **今日待办**：带"去处理 →"入口
- **本月经营**：录单数、成交、净入账、投递成交率
- **快捷功能**：AI 批量录单 / 订单管理 / 投递审核 / 财务流水 / 地图看单 / 消息通知

## 3. 把微信里的订单搬进系统：AI 批量录单

1. 快捷功能点「**AI 批量录单**」
2. 把微信聊天里的订单文本**整段复制粘贴**进输入框（支持多条连在一起）
3. 点「开始 AI 识别」，等 10~30 秒
4. **逐条校对**：每条订单会标出「可直接确认 / 待确认 / 无法创建」和置信度；
   字段缺失或存疑的会标 ⚠ 原因——点「编辑」修正后即可
5. 底部点「**批量创建 N 条订单**」（有问题的条目会自动跳过并提示）
6. 创建成功的订单立刻出现在「订单管理」里

## 4. 审核教员投递

- 工作台点「**待审核投递**」或快捷功能「投递审核」
- 左栏选订单，右栏看教员投递卡（院校背景 / 历史成交 / 评分 / 联系方式）
- 动作：加入候选 → 确认定金 → 开始试课 → 确认尾款 → 完成订单；不合适就拒绝
- 每一步都有确认提示，按业务节奏操作即可

## 5. 看一个订单的全部情况：订单工作区

- 「订单管理」里点任意订单的**名称**
- 一屏看到：订单状态 / 生命周期进度条 / 教学要求与原始信息 / 教员投递列表（含画像与状态）/ 资金状态（定金、尾款已收待收）
- 需要处理投递就点「去审核投递」；不要的单可以「归档」，归档了还能「重新发布」

## 常见问题

- **手机上看会不会乱？** 不会——全站按手机优先设计，电脑宽屏自动变成左右分栏工作台
- **AI 识别错了怎么办？** 校对页每条都能改，改完再创建；识别不了的会明确标注而不是瞎填
- **数据安全吗？** 家长联系方式仅中介可见，敏感操作都有操作留痕（谁、何时、做了什么）

## 反馈方式

任何看不懂、找不到、觉得别扭的地方，**直接在微信里截图 + 一句话描述**发给平台，
原话越具体越有帮助（比如"我找半天不知道去哪审核"比"审核不好用"有用得多）。
